One-line software patch note for a bug in real life — the brain replaying an
embarrassing memory at 3 a.m. with no skip button. Built for the
[Real-Life Patch Notes: The Comedy Changelog](https://make.fun) competition on
[make.fun](https://make.fun).

Run with Node 22: `node main.ts` writes the patch note to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
